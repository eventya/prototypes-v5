„Schimbat de client" nu este o eroare. Este dreptul lui și, uneori, chiar adevărul. De aceea semnalul spune „de discutat", nu „de reparat": un client care se declară neconform este un client care are nevoie de ajutorul nostru.
Ecranul acesta este ultimul livrat, în Etapa 4. Conformitatea legală a site-urilor nu depinde de el: este doar un instrument de lucru pentru noi. Dacă timpul este scurt, de aici se taie.
